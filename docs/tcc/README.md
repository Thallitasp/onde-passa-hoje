# Estruturação preliminar para TCC

> Este material é uma proposta inicial de trabalho acadêmico. O curso, o manual da instituição, o orientador, o calendário e o formato de entrega ainda precisam ser confirmados. Não representa um projeto aprovado e não apresenta resultados de avaliação que ainda não foram coletados.

## Tema provisório

Desenvolvimento e avaliação de uma aplicação web para centralizar informações diárias de partidas de futebol.

## Recorte recomendado

Investigar como uma aplicação pode reunir agenda, horários, transmissões e informações pré-jogo de fontes públicas distintas, indicando a origem dos dados e sinalizando ausências, divergências e conteúdo desatualizado. Para manter o TCC viável, a avaliação pode começar por uma competição e um período definidos com o orientador.

## Pergunta de pesquisa provisória

Como integrar e apresentar dados públicos de partidas de futebol de forma rastreável, indicando a fonte e a incerteza das informações de transmissão e pré-jogo?
